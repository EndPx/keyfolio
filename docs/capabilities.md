## Official sources and what was actually inspected

- S1 [Confidential owner authentication](https://docs.near-intents.org/integration/distribution-channels/1click-api/authentication): integration token and owner session distinction. Endpoint access/refresh scopes still require actual tests.
- S2 [Account history](https://docs.near-intents.org/api-reference/account/get-transaction-history): invite-only history; no full-account external-interface completeness claim accepted. Detailed permission/terms questions:[KF-01 research](evidence/KF-01/access-research.md).
- S3 [NEAR NFT standard](https://docs.near.org/primitives/nft/standard): core transfer/read/callback and metadata interfaces; standard existence is not our entitlement implementation.
- S4 [NEAR FT standard](https://docs.near.org/primitives/ft/standard): FT and receiver callback interfaces. Subscription asset choice remains G02.
- S5 [Wallet Selector repository](https://github.com/near/wallet-selector) and [core wallet interface](https://raw.githubusercontent.com/near/wallet-selector/main/packages/core/src/lib/wallet/wallet.types.ts): optional message-signing and transaction interfaces inspected. Previously guessed docs.near.org/tools/wallet-selector returned404; do not cite it as a working guide.
- S6 [NEAR RPC introduction](https://docs.near.org/api/rpc/introduction): JSON-RPC/finality/state/transaction methods. S7 [official RPC provider directory](https://docs.near.org/api/rpc/providers): ecosystem endpoint options and published-limit caveats; no unmeasured SLA claims.
- S8 [Confidential swaps](https://docs.near-intents.org/integration/distribution-channels/1click-api/quickstart/confidential-swaps): supported integration path; our wallet/settlement/coverage acceptance NOT_RUN.
- S9 [NEAR oracle directory and methods](https://docs.near.org/primitives/oracles): NEAR deployments listed, current feed read documented. Pyth/Outlayer are ecosystem-deployed integrations, not NEAR-owned services. Historical coverage must be verified with their maintained APIs/terms.
- S10 [CoinGecko historical range API](https://docs.coingecko.com/reference/coins-id-market-chart-range): time-range historical-price candidate. An endpoint in docs is not proof of required granularity, exact token mapping or affordable permission for Keyfolio. No API trial/key/purchase.
- S11 [near-workspaces-rs](https://github.com/near/near-workspaces-rs): NEAR-owned test tooling for controlled sandbox/testnet. No runtime outcome inferred from repository description.
