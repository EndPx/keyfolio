# KF-05 direct NFT transfer storage — 2026-11-12

Status: Codex ACCEPTED PASS_LOCAL for ordinary `nft_transfer` only. No public-network transaction, signing, funding, deployment, shared funder or secret access occurred. Worker left source uncommitted; coordinator publication follows independent review.

After the normal one-yocto, owner and lock checks, `nft_transfer` records storage usage, performs the owner/index and epoch updates, then charges the sender's available native storage credit for positive net growth using the existing `charge_storage_growth` path. This charge uses exact actual bytes and the chain storage byte price; the receiver and any sender pending native payout are not debited. If there is no increase, no user credit is credited or deducted; a decrease frees contract-level stake and does not create a customer refund. If positive growth exceeds available credit or registration is missing, the receipt panics and chain execution rolls back the transfer. Subscription terms, expiration and refund entitlement remain attached to the NFT. `nft_transfer_call` and its resolver are unchanged.
